# Especificaciones de Imágenes para +chamba Landing Page

## Guía completa de imágenes requeridas para la landing page profesional

---

## 1. HERO SECTION - Imagen Principal
**Ubicación:** Parte superior de la página, debajo del título hero

**Especificaciones:**
- **Tamaño:** 1200 x 675 píxeles (16:9)
- **Formato:** JPG o PNG
- **Peso máximo:** 300KB (optimizada para web)
- **Contenido:** Mockup de la plataforma +chamba mostrando:
  - Laptop con el dashboard abierto
  - Smartphone mostrando una tienda online
  - Interfaz limpia y moderna
  - Productos visibles en el catálogo

**Recomendaciones:**
- Usar mockups realistas (tipo mockuper.net o smartmockups.com)
- Fondo degradado o neutro que no compita con el contenido
- Preferiblemente con screenshots reales de la plataforma
- Luz y colores que complementen la paleta naranja/roja de la marca

**Herramientas sugeridas:**
- Figma para diseñar el mockup
- Canva Pro (plantillas de mockups)
- Smartmockups.com
- Shots.so para screenshots con estilo

## 2. FEATURES SECTION - Imágenes de Características (3 imágenes)

### Feature Image 1: Dashboard de Tienda Online
**Especificaciones:**
- **Tamaño:** 800 x 600 píxeles (4:3)
- **Formato:** JPG o PNG
- **Peso máximo:** 200KB
- **Contenido:**
  - Screenshot del panel de administración
  - Vista del catálogo de productos
  - Interfaz mostrando facilidad de uso
  - Botones de "agregar producto", estadísticas básicas

### Feature Image 2: Sistema de Pagos
**Especificaciones:**
- **Tamaño:** 800 x 600 píxeles (4:3)
- **Formato:** JPG o PNG
- **Peso máximo:** 200KB
- **Contenido:**
  - Pantalla de métodos de pago
  - Logos de Yape, Plin, Visa, Mastercard
  - Interfaz de confirmación de pago
  - Dashboard de transacciones

### Feature Image 3: Panel de Logística
**Especificaciones:**
- **Tamaño:** 800 x 600 píxeles (4:3)
- **Formato:** JPG o PNG
- **Peso máximo:** 200KB
- **Contenido:**
  - Vista del sistema de tracking de pedidos
  - Mapa o timeline de envío
  - Estado de pedidos
  - Integración con couriers

**Recomendaciones para las 3:**
- Screenshots reales de la plataforma con datos de prueba
- Si aún no existe la plataforma, usar wireframes de alta fidelidad
- Añadir blur en datos sensibles
- Mantener consistencia visual entre las 3 imágenes

## 4. ABOUT SECTION - Fotos del Equipo (3 fotos)

### Fotos de Fundadores/as
**Especificaciones:**
- **Tamaño:** 500 x 500 píxeles (1:1 - se recortará circular)
- **Formato:** JPG
- **Peso máximo:** 100KB por foto
- **Cantidad:** 3 fotos (CEO, CTO, COO)

**Contenido:**
- Fotos profesionales de headshot
- Fondo neutro o difuminado
- Buena iluminación (luz natural o de estudio)
- Expresión amigable y profesional
- Vestimenta business casual

**Recomendaciones:**
- Mantener estilo consistente entre las 3 fotos
- Evitar selfies o fotos casuales
- Considerar contratar fotógrafo profesional
- Si no están disponibles aún: usar placeholders con iniciales

**Alternativas temporales:**
- Avatares generados con IA (thispersondoesnotexist.com)
- Ilustraciones personalizadas
- Placeholders con gradientes y letras

## 5. OPTIMIZACIÓN GENERAL

### Checklist de calidad para TODAS las imágenes:

**Formato y Compresión:**
- ✅ Usar JPG para fotos (mejor compresión)
- ✅ Usar PNG solo si se necesita transparencia
- ✅ Comprimir con TinyPNG.com o Squoosh.app
- ✅ Objetivo: máximo 300KB por imagen

**Resolución:**
- ✅ Usar 2x el tamaño para pantallas Retina
- ✅ Servir versiones responsivas con `<picture>` o `srcset`
- ✅ Considerar formato WebP para mejor compresión

**SEO:**
- ✅ Nombres de archivo descriptivos: `hero-dashboard-chamba.jpg`
- ✅ Atributos ALT descriptivos
- ✅ Lazy loading para imágenes below the fold

**Consistencia Visual:**
- ✅ Paleta de colores alineada con la marca (naranjas, rojos, blancos)
- ✅ Mismo estilo fotográfico
- ✅ Iluminación y temperatura de color similar
